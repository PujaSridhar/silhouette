      What this is. A working demo of a styling reasoning engine: a constraint solver over explicit rules, not a recommender. The reference implementation is Python (18 rules, 30 hand-annotated garments). This page re-implements the geometry and rule conditions in JavaScript so the sliders work live.

      Why the badge. A second implementation is a second chance to be wrong, so the page replays outfits whose answers the Python engine computed and compares every number and every fired rule. If the port drifts, the badge turns red and says which case failed.

      Honest limits. volume and structure are hand-judged by one person, landmarks are measured from one body, and the rule weights are set by judgement rather than fitted — the eval harness exists to fix that last one.
